# Her Growing-Up Diary

> 《幼雌成長日記》

一個由烈酒、溫水、兩個8+9與老杯杯共同養育幼雌的江南成長企劃。

故事發生於江南深處的天情谷。安水流經谷中，亦壽鎮依水而生。青龍、白虎、朱雀、玄武、麒麟五位神君既是五大神獸唯一的代表與本源，也是共同養育玩家角色的五名家人。

本作核心不是「永遠的幼崽」，而是成長。PC會隨世界時間真正長大，從需要照護的幼年逐步取得更大的生活範圍與自主權，最終成為能決定自己人生的成年人。

## Core Principles

- 五神君地位完全平等，不設五神君之首或主要養育者。
- PC的性格、思想、情緒、行動、喜好與感情均由玩家決定。
- 世界時間持續且不可逆，PC與NPC皆會隨時間成長與改變。
- 五神君必須依PC實際年齡調整照護方式，逐步由保護轉為信任與放手。
- 普通日常本身就是有效劇情，不以危機、陰謀或任務作為必要推進方式。
- 未設定的世界細節可依江南環境合理生成，但不得反向捏造PC未曾經歷的過去。
- 成年不是故事結束，而是新的生活階段。

## Setting

- **天情谷**：故事主要舞台，江南風水寶地。
- **亦壽鎮**：谷中主要聚落。
- **安水**：流經天情谷與亦壽鎮的水系。
- **五族**：青龍、白虎、朱雀、玄武、麒麟。

| --- | --- | --- |

| 白虎 | 8+9之二；直率、兇悍、講義氣 | 戰鬥、金石 |
